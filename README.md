# 🍽️ Restaurant POS System

## 🖥️ Overview
**Restaurant POS System (2023)** is a comprehensive **desktop-based point of sale (POS)** solution built using **C#**.  
The system is designed to automate and manage all restaurant operations — from daily order entry and invoice printing to inventory tracking and advanced reporting — through a fast, secure, and user-friendly interface.

This POS system enables both **cashiers** and **restaurant managers/owners** to efficiently handle sales, monitor stock, and review detailed reports — all within a single Windows desktop environment.

---

## 🚀 Key Features

### 👨‍🍳 For Cashiers
- 💰 **Daily Sales Entry** — Record customer orders and transactions seamlessly.  
- 🧾 **Instant Invoice Printing** — Generate and print customer receipts using **Crystal Reports**.  
- 📅 **Daily Reports** — View daily sales summaries, total revenue, and payment breakdowns.  
- 🔍 **Transaction History** — Easily access and reprint invoices when needed.  
- 💵 **Cash Control** — Track daily cash input and output per cashier session.  

---

### 🏢 For Managers / Owners
- 🧑‍💼 **User & Role Management** — Create and manage cashier/admin accounts with role-based permissions.  
- 🍔 **Menu Management** — Add, edit, or delete food items with prices, descriptions, and images.  
- 🏷️ **Category Organization** — Structure items under specific categories for easier navigation.  
- 📦 **Inventory Management** — Real-time stock updates after each sale or return.  
- 📊 **Advanced Reporting System**
  - Generate **daily, weekly, and monthly reports** for sales, invoices, and returns.  
  - Apply **filters and sorting** (by user, category, or date).  
  - Export reports as **PDF files** or **Crystal Report printouts**.  
- 🧾 **Crystal Reports Integration** — All invoices and reports are generated using **Crystal Reports** for a professional and printable format.  

---

## 📦 Inventory & Reports
- 🔢 **Live Inventory Tracking** — Automatically adjust item quantities after each sale.  
- 🧮 **Comprehensive Reports**
  - **Sales Reports:** Daily, weekly, and monthly summaries.  
  - **Return Reports:** Detailed tracking of returned orders and reasons.  
  - **Order Reports:** Status-based and date-filtered analysis.  
- 🧾 **Crystal Report Printing** — Generate detailed invoices and export formatted reports.  
- 📄 **PDF Export Support** — Optionally export filtered reports as PDF for record-keeping.  

---

## ⚙️ System Workflow
1. The **cashier logs in** and records new customer orders.  
2. The system **calculates totals**, applies any discounts, and **prints an invoice via Crystal Reports**.  
3. **Inventory stock** is updated automatically with each sale or return.  
4. The **manager or owner** reviews daily reports and transaction summaries.  
5. Reports can be **exported as PDF** or printed directly for archiving.

## 🧠 Purpose
The system was developed to help restaurants **digitize their sales process**, improve **reporting accuracy**, and ensure **real-time tracking** of inventory and revenue.  
It provides a centralized way to:
- Record and print customer invoices.
- Monitor stock movement in real time.
- Generate **daily financial summaries** automatically.
- Support **managerial decision-making** with detailed reporting.
